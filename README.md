# Ela+ — Landing Page

Landing page responsiva em React + Vite, com identidade visual premium em tons de rosa, vinho e off-white.

## Requisitos
- Node.js 18 ou superior
- npm

## Executar localmente

```bash
npm install
npm run dev
```

Abra o endereço informado pelo Vite (normalmente http://localhost:5173).

## Gerar versão de produção

```bash
npm run build
npm run preview
```

## Personalização
- Conteúdo e componentes: `src/App.jsx`
- Estilos e responsividade: `src/styles.css`
- Metadados e título: `index.html`

O mockup do celular é ilustrativo e foi construído em CSS/React. Substitua-o por capturas reais do aplicativo quando estiverem disponíveis. O botão principal atualmente direciona para o repositório GitHub; troque o link pelo endereço da Play Store quando o app for publicado.

As informações de ciclo exibidas no mockup são dados fictícios usados apenas para apresentação visual.
